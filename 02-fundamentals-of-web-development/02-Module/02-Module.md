# Sustentación del Módulo 2: Developing Sites for the Web

**HTML, CSS y JavaScript**: En este módulo, aprendí sobre cómo crear sitios web usando HTML, CSS y JavaScript. HTML proporciona la estructura básica de la página, CSS se encarga del diseño y estilo, y JavaScript agrega interactividad, como validación de formularios o mensajes emergentes.

**Compatibilidad entre dispositivos**: También vimos cómo los navegadores interpretan el código HTML para mostrarlo de forma legible en diferentes dispositivos. El diseño debe ser responsivo, es decir, adaptarse a pantallas de diferentes tamaños como en dispositivos móviles y computadoras de escritorio.

**Mejoras de HTML5**: Una de las mejoras más importantes de HTML5 son las nuevas etiquetas semánticas que permiten una mejor organización del contenido. Además, JavaScript es crucial para la interacción con el usuario, como la creación de formularios dinámicos o la actualización de contenido sin necesidad de recargar la página.
