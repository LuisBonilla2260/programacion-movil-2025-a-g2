# 📹 Video 2: GitHub Tutorial - Beginner's Training Guide
Este video me ofreció una guía introductoria sobre el uso de **GitHub**, enfocándose en cómo gestionar proyectos y colaborar con otros desarrolladores. Aprendí a navegar por la interfaz de GitHub, comprendiendo secciones clave como repositorios, issues, pull requests y el README.

Se explicó cómo crear un nuevo repositorio, agregar archivos, realizar commits y manejar ramas para trabajar en diferentes versiones del proyecto. También se mostró cómo colaborar con otros mediante forks y pull requests, permitiendo proponer cambios y revisarlos antes de integrarlos al proyecto principal.

Además, el tutorial destacó la importancia de los issues para rastrear tareas y errores, facilitando la gestión del proyecto. Aprendí a asignar etiquetas, responsables y a cerrar issues una vez resueltos.

Este video reforzó mi comprensión de GitHub como una herramienta colaborativa esencial en el desarrollo de software, ayudándome a gestionar proyectos de manera más organizada y eficiente.
