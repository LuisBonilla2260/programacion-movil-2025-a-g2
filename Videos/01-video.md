# 📹 Video 1: Git Tutorial For Beginners 2022 | Git & GitHub Complete Tutorial | Learn Git in 2 hrs | Simplilearn
En este video, aprendí los fundamentos de **Git** y **GitHub**, herramientas esenciales para el control de versiones en el desarrollo de software. Comprendí cómo Git permite rastrear cambios en el código, facilitando la colaboración entre desarrolladores y la gestión de proyectos.

El tutorial cubrió comandos básicos como `git init`, `git add`, `git commit`, `git push` y `git pull`, que son fundamentales para trabajar con repositorios locales y remotos. También se explicó cómo crear ramas (`branches`) para desarrollar nuevas funcionalidades sin afectar la versión principal del proyecto.

Además, se abordó el uso de **GitHub** como plataforma para alojar repositorios en la nube, permitiendo compartir proyectos y colaborar con otros desarrolladores. Aprendí a crear un repositorio en GitHub, clonarlo en mi máquina local y sincronizar cambios entre ambos entornos.

Este video me proporcionó una base sólida para comenzar a utilizar Git y GitHub en mis proyectos de desarrollo web, mejorando mi flujo de trabajo y facilitando la colaboración en equipo.
