# 📹 Video 3: Git and GitHub for Beginners - Crash Course
Este curso intensivo me proporcionó una visión general de **Git** y **GitHub**, ideal para principiantes. Comenzó explicando qué es el control de versiones y por qué es crucial en el desarrollo de software, especialmente cuando se trabaja en equipo.

Aprendí a instalar Git, configurar mi identidad de usuario y crear un repositorio local. Se cubrieron comandos esenciales como `git status`, `git diff`, `git log` y `git reset`, que ayudan a monitorear y controlar los cambios en el código.

El video también abordó la conexión entre Git y GitHub, mostrando cómo crear un repositorio remoto, conectarlo con el local y sincronizar cambios mediante `git push` y `git pull`. Además, se explicó cómo manejar conflictos de fusión (`merge conflicts`) y resolverlos adecuadamente.

Este curso me brindó una comprensión práctica de cómo utilizar Git y GitHub en proyectos reales, mejorando mi capacidad para colaborar y mantener un historial claro de los cambios en el código.
